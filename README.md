One funny fortune cookie line for an AI agent.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only, no network) writes the entry text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry text

```
Your next deploy will succeed — but only after you blame the cache, restart twice, and apologize to the server.
```
